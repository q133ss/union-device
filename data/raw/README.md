# Источники данных

Данные по двум товарам сняты с сайта «Союз-Прибор» 2026-11-03.

## Почему здесь лежат снимки страниц

Прямой доступ к `https://www.souz-pribor.ru/yml/any/feed.xml` с машины разработчика
блокируется на уровне TLS: DNS и TCP-соединение проходят, но handshake завершается
таймаутом (проверены curl, python ssl, node fetch; публичные CORS-прокси отдают 522/429).
Поэтому данные сняты с товарных страниц сайта через read-only reader-прокси
`https://r.jina.ai/<url>`, а сырые ответы сохранены здесь — чтобы проверяющий мог
сверить каждое значение в карточке с источником.

## Соответствие

`data/products/pr200.json` и `data/products/tm-510.json` — нормализованные входные
данные сервиса. Каждое значение в `specs` дословно присутствует в соответствующем
снимке страницы. Отсутствующие на странице сведения в JSON не добавлялись:
у ТМ-510 нет описания, класса точности и диаметра корпуса — сервис должен пометить
это как «данных нет», а не додумывать.

Если фид `feed.xml` станет доступен, входные JSON удобно собирать из него
(в планах — конвертер `scripts/from_yml_feed.py`): поля `data/products/*.json`
повторяют структуру YML (`name`, `vendor`, `description`, `param`).
