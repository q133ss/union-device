# Источники данных

Данные по двум товарам взяты с сайта «Союз-Прибор»: YML-фид магазина и товарные
страницы. Снимки источников лежат здесь, чтобы каждое значение в карточке можно
было сверить.

## Что даёт фид, а что — страница

Фид `https://www.souz-pribor.ru/yml/any/feed.xml` (37 МБ, 47 978 предложений,
132 бренда) — первоисточник магазина: название, `typePrefix`, производитель,
категория, ссылка, цена, наличие, параметры SKU. Описаний в фиде нет вообще
(`<description>` не встречается ни у одного предложения), технических
характеристик у наших предложений тоже почти нет — только «Код товара» и
«Артикул».

Поэтому для карточки данные собираются из двух источников:

| Что | Откуда |
|---|---|
| производитель, категория, ссылка, SKU, цена, наличие | YML-фид (`scripts/from_yml_feed.py`) |
| технические характеристики, описание | товарная страница (`data/raw/*.page.md`) |

## Файлы

| Файл | Источник | Что внутри |
|---|---|---|
| `feed-offers.xml` | `https://www.souz-pribor.ru/yml/any/feed.xml` | выдержка: два нужных предложения и их категории (полный фид 37 МБ в репозиторий не кладём) |
| `pr200.page.md` | https://www.souz-pribor.ru/product/pr200/ | описание ПР200, блок «Характеристики», модификации |
| `tm-510.page.md` | https://www.souz-pribor.ru/product/tm-510/ | таблица исполнений ТМ-510 (диапазоны, резьба, штуцер); описания и класса точности на странице нет |

## Соответствие

`data/products/pr200.json` и `data/products/tm-510.json` — входные данные сервиса:

* `manufacturer`, `category`, `source_url`, блок `feed` — из фида;
* `specs`, `description` — со страницы товара, дословно;
* отсутствующие на странице сведения не добавлялись: у ТМ-510 нет описания,
  класса точности и диаметра корпуса — сервис должен пометить это как
  «данных нет», а не додумывать.

Пересобрать метаданные из фида:

```bash
python scripts/from_yml_feed.py --feed feed.xml --match "ТМ-510" --limit 1 --print
```

## История: доступ к фиду

Фид отдаётся только с российских адресов. Через VPN с иностранным выходом
(TLS-handshake до `souz-pribor.ru` зависает — проверено `curl`, `python ssl`,
`node fetch` и Chrome через CDP) фид недоступен. Без VPN файл скачивается
целиком: 37 156 849 байт за ~2,5 секунды. Первая версия данных собиралась со
страниц товаров, потому что фид был недоступен; после проверки фида
производитель ТМ-510 исправлен: **РОСМА**, а не «Манотомь» (фильтр по бренду на
сайте показывал этот товар в обеих категориях — фид является первоисточником).
